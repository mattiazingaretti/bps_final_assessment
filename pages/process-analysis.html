Issues Identification & Improvement Opportunities

ISS-001 CRITICAL
Responsible Area

Talent Management / IT Security

Critical Data Security Vulnerability

Detailed Description

Sensitive employee personal data including performance evaluations, attendance records, and TOEIC examination results are stored in an Excel file named "English Students 2012 Final Version" on a Google Drive folder with public access. This represents a severe data protection vulnerability with potential GDPR compliance implications.

Associated Implications

  • • GDPR non-compliance: potential fines up to €20M or 4% of global revenue
  • • Employee privacy breach and trust erosion
  • • Reputational damage if data breach occurs
  • • Internal audit failure - immediate finding

Evidence Source

"Findings and conclusions are recorded in an Excel spreadsheet ('English Students 2012 Final Version') and stored in a shared Google Drive with public access." — Activity 4, Case Study

ISS-002 HIGH
Responsible Area

Talent Management

Absence of Standardized Evaluation Criteria

Detailed Description

The process lacks standardized criteria for evaluating employee progress and determining reimbursement eligibility. Different Talent Management analysts apply inconsistent methods: some conduct fortnightly progress meetings while others rely solely on TOEIC examination results. This leads to subjective and potentially unfair decisions.

Associated Implications

  • • Inconsistent treatment of employees across the organization
  • • Potential discrimination claims
  • • Audit finding: lack of control standardization
  • • Employee dissatisfaction and demotivation

Evidence Source

"Sometimes, we might struggle a bit with reimbursements because it pretty much depends on what criteria we use to determine eligibility. Some of us are more picky around examining the progress... Others are more result oriented." — Employee Comment, Appendix

ISS-003 MEDIUM
Responsible Area

HR / Process Owner

Process Not Formally Documented

Detailed Description

The language course enrollment process lacks formal documentation including Standard Operating Procedures (SOPs), process flowcharts, and policy documents. The process relies entirely on institutional knowledge ("tribal knowledge") passed down informally between employees.

Associated Implications

  • • Knowledge loss when employees leave
  • • Inconsistent process execution
  • • Difficulty training new employees
  • • Audit finding: absence of process documentation

Evidence Source

"This is the best process I've ever seen… it's so effective that it's not even documented. Everyone in the organization knows it by heart because it's SO EASY!" — Employee Comment, Appendix

ISS-004 MEDIUM
Responsible Area

HR / IT

Manual Legacy Systems and Processes

Detailed Description

The process relies on outdated manual systems: an Excel spreadsheet from 2012, email-based approval workflows, and paper-based reimbursement forms. There is no integrated HR system or workflow automation. This creates inefficiencies, delays, and error-prone operations.

Associated Implications

  • • High administrative burden
  • • Data entry errors and inconsistencies
  • • No audit trail for approvals
  • • Employee frustration with manual processes

Evidence Source

"I feel very supported by the Talent Management team, even when they request me to submit all tickets and expenses using manual reimbursement forms." — Employee Comment, Appendix

IMP-001 URGENT → Addresses ISS-001
Responsible Area

Implement Secure HRIS with Role-Based Access Control

Description

Deploy an enterprise-grade Human Resource Information System (HRIS) such as SAP SuccessFactors, Workday, or Oracle HCM with role-based access control (RBAC), data encryption at rest and in transit, and comprehensive audit logging. Migrate all employee training data from Google Drive to this secure platform.

Expected Benefits

  • ✓ 100% GDPR compliance for employee data
  • ✓ Eliminate €20M+ fine risk
  • ✓ Full audit trail for all data access
  • ✓ Immediate audit readiness
